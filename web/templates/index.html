Vercel & GitHub Actions Cloud Variables

Required environment variables and secrets to link Vercel and GitHub Actions together:

GitHub Secrets: (Repository → Settings → Secrets and variables → Actions)
  • GEMINI_API_KEY - Your Google Gemini AI Studio key (Required)
  • YOUTUBE_CLIENT_SECRETS_JSON - Contents of your client_secrets.json (Optional for auto-upload)
  • YOUTUBE_TOKEN_JSON - Contents of your authenticated token.json (Optional for auto-upload)
Vercel Environment Variables: (Project Settings → Environment Variables)
  • GITHUB_PAT - Personal Access Token with repo/actions dispatch permissions
  • GITHUB_OWNER - harshithphtlt-crypto
  • GITHUB_REPO - youtube
